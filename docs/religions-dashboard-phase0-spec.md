# Religions Dashboard: Phase 0 Foundation Spec

Version 0.1. Status: draft for sign-off. Nothing downstream starts until this locks.

---

## 1. Product principles

1. **One time cursor, many lenses.** A single global time state. Timeline, map, and every future module read and write the same cursor.
2. **Content is a database, prose is a rendering.** Every deep dive is authored as structured fields plus prose. The belief matrix, year wheel, life-arc rites, and compare mode are extracted from those fields, never rewritten.
3. **Identical schema per tradition.** Comparability is a product feature, so the template never bends per tradition.
4. **Describe, never evaluate.** Uniform attribution framing for all supernatural claims across all traditions (see Section 9).
5. **Every phase ships a complete site.** No phase depends on an unshipped future phase.

## 2. Launch traditions and taxonomy

### 2.1 The launch ten

Christianity, Islam, Judaism, Hinduism, Buddhism, Sikhism, Chinese traditions (Confucian-Taoist-folk cluster), Jainism, Shinto, Zoroastrianism.

### 2.2 Taxonomy rules

- Maximum drill depth: 3 levels (tradition, family, denomination). Deeper granularity is prose inside deep dives, not lanes.
- Every node carries: `id`, `name`, `parent`, `founded` (year + precision), `status` (living | historical), `adherents` (estimate + source + year), `contested` (bool + note), `summary` (1 sentence).
- **Currents vs branches.** Movements that cut across branches (Sufism, Kabbalah, bhakti, charismatic renewal) are modeled as `currents`: tags that span nodes, never lanes. This is a hard rule; Sufism is not a lane under Islam.
- **Classification policy.** Tree structure follows academic consensus (Oxford/Cambridge handbook conventions). Demographic categories follow Pew. Where membership is contested (Ahmadiyya within Islam, Latter-day Saints within Christianity), the group is placed per self-identification, with `contested: true` rendered visually (badge + note citing both positions). This policy is uniform and non-negotiable per entry.

## 3. Event schema

The single most load-bearing structure in the product. Every timeline, filter, map pin, and influence thread hangs off this.

| Field | Type | Rules |
|---|---|---|
| `id` | slug | Unique, stable, never recycled |
| `title` | string | Max 60 chars, display name |
| `year_start` | integer | Astronomical year: negative = BCE. Sorting is pure integer math |
| `year_end` | integer, optional | For ranges (reigns, compilations, wars) |
| `precision` | enum | exact, year, decade, century, era. Drives rendering ("c. 563 BCE") |
| `display_date` | string | Human-readable override, generated by default |
| `traditions` | array | Tradition ids affected. Multi-tradition events are one record, never duplicated |
| `branch_path` | array of paths | e.g. `christianity/protestant/lutheran`. Determines lane placement at every drill level |
| `type` | enum | See 3.1 |
| `importance` | 1 to 5 | Per rubric in Section 4. Controls zoom-level visibility |
| `region` | array | Region ids (Section 6). Links event to map |
| `location` | lat/lng, optional | Precise pin where one exists |
| `summary` | string | 1 to 2 sentences, card text |
| `body` | markdown, optional | Panel text, 100 to 300 words |
| `media` | array, optional | Image refs, each with credit + license |
| `sources` | array | Citations. Minimum counts per Section 9 |
| `contested` | bool + note | Disputed date, historicity, or interpretation. Renders visually |
| `links` | object | Related event ids, figure ids, deep-dive anchors |
| `influence` | array, optional | `{target, relation, contested}` edges feeding influence threads (Phase 3) |
| `tags` | array | Freeform filter fuel |

### 3.1 Event type enum

`founding`, `schism`, `text` (composition or canonization), `figure` (birth, death, ministry), `council`, `political` (conquest, adoption, edict), `reform`, `expansion` (migration, mission), `persecution`, `construction` (temple, site), `encounter` (interfaith contact), `modern` (movement, event post-1800).

### 3.2 Example record

```json
{
  "id": "council-of-nicaea-325",
  "title": "First Council of Nicaea",
  "year_start": 325,
  "precision": "exact",
  "traditions": ["christianity"],
  "branch_path": ["christianity"],
  "type": "council",
  "importance": 5,
  "region": ["anatolia"],
  "location": {"lat": 40.43, "lng": 29.72},
  "summary": "First ecumenical council, convened by Constantine. Produced the original Nicene Creed and condemned Arianism.",
  "sources": ["oxford-early-christianity-2008", "britannica-nicaea"],
  "contested": false,
  "links": {"figures": ["constantine-i", "athanasius"], "events": ["edict-of-milan-313"]},
  "tags": ["creed", "christology", "roman-empire"]
}
```

## 4. Importance rubric and density budget

| Rank | Bar | Zoom level | Target volume |
|---|---|---|---|
| 5 | Civilization-scale: foundings, the Hijra, 1054, the Reformation's start | Millennia view | 3 to 5 per tradition, total |
| 4 | Tradition-defining: major councils, canonizations, internal schisms | Century view | 10 to 15 per tradition |
| 3 | Significant: dynastic adoptions, key figures' works, landmark constructions | Decade view | 30 to 50 per tradition |
| 2 | Notable: regional developments, secondary figures | Close zoom | As sourced |
| 1 | Texture: local, enrichment, anecdotal | Maximum zoom only | Optional |

**Density budget:** at any zoom level, no more than ~8 visible events per lane per viewport width. If a rank tier overflows the budget in a period, events get demoted, not crowded. The rubric serves the canvas, not the reverse.

## 5. Deep-dive page template

Fourteen sections, identical order for all ten traditions. Bracketed items are structured fields, not prose, and feed later modules.

1. **Overview**: one-screen summary + stat box [adherents, founded, origin region, primary texts, symbol]
2. **Origins and history**: prose + embedded link to the timeline pre-filtered to this tradition
3. **Core beliefs**: prose keyed to the matrix dimensions [matrix cells, Section 7]
4. **Sacred texts**: canon table [text, language, composition date, canonical status per branch]
5. **Branches**: interactive tree snippet [taxonomy nodes]
6. **Practices and worship**: prayer, liturgy, meditation [practice records]
7. **Law and ethics**: dietary, dress, moral framework [matrix cells]
8. **Rites of passage**: birth, coming of age, marriage, death [life-arc records, Phase 3]
9. **Holy days**: [festival records: name, date rule, calendar system; feeds year wheel, Phase 3]
10. **Sacred sites**: map snippet [site records: name, location, significance; feeds sites layer, Phase 2]
11. **Key figures**: [figure records: name, dates, role, links; feeds network, Phase 4]
12. **Demographics**: Pew chart [country-level data refs]
13. **Common misconceptions**: 3 to 5, each sourced
14. **Sources and further reading**

Target length: 5,000 to 8,000 words per tradition plus structured records.

## 6. Region and era-snapshot model (map foundation)

- **Region ids**: modern ISO countries plus ~25 historical macro-regions (Levant, Mesopotamia, Anatolia, Gangetic Plain, Deccan, Transoxiana, Maghreb, Horn of Africa, etc.). Events reference either.
- **Era snapshots** (Phase 2 builds these; Phase 0 locks the list): 500 BCE, 1 CE, 300, 600, 750, 1000, 1200, 1500, 1700, 1850, 1950, 2020.
- Each snapshot: per region, `dominant` tradition, `significant` minorities (>10%), and a `confidence` grade (A: well-documented, B: scholarly estimate, C: speculative, rendered hatched).
- Pre-500 BCE is deliberately out of scope for the map: evidence is too thin to polygon honestly. The timeline covers it; the map does not.

## 7. Belief matrix dimensions

Thirteen columns. Every cell = `{value, nuance, source}` where `value` is enum-ish to make cells filterable and `nuance` is 1 to 3 sentences.

1. Concept of the divine (monotheist, non-theist, polytheist, monist, varies)
2. Cosmology and creation
3. Afterlife (resurrection, reincarnation, rebirth, ancestral realm, varies, none)
4. Path to salvation or liberation
5. Scripture and authority structure
6. Clergy and leadership
7. Worship form and frequency
8. Dietary law
9. Dress and modesty codes
10. Conversion and missionary stance
11. Core ethical frame
12. View of other religions
13. Calendar system (solar, lunar, lunisolar)

Rows: the ten traditions plus major branches where a cell genuinely differs (e.g., Theravada vs Vajrayana on cosmology). Roughly 15 rows at launch.

## 8. Glossary schema

`term`, `original` (script + transliteration), `pronunciation` (audio ref, Phase 3), `definition` (max 50 words), `tradition(s)`, `see_also`. Every technical term in any prose gets wrapped at authoring time. Target: ~300 terms at launch.

## 9. Sourcing and neutrality rules

### 9.1 Source tiers

- **T1**: academic (Oxford and Cambridge handbooks, Brill's Encyclopaedia of Islam, Encyclopaedia Judaica, peer-reviewed journals)
- **T2**: demographic authorities (Pew Research, national censuses)
- **T3**: reputable general reference (Britannica, BBC archive)
- **T4**: tradition-internal sources (catechisms, official denominational statements). Allowed, and required, for self-description of belief; always labeled as internal.

### 9.2 Hard rules

1. Every event of importance 3+ cites at least one T1 to T3 source.
2. Every matrix cell cites T1 or labeled T4.
3. Every contested item cites both positions.
4. Adherent counts are Pew unless explicitly noted otherwise.
5. Never cite aggregator religion websites.
6. Dates follow academic consensus; uncertainty renders as "c." via `precision`, never silently rounded.

### 9.3 Neutrality rules

1. Uniform attribution for supernatural claims across all traditions: "according to [tradition]," "in [tradition's] account." Never asymmetric (not "Jesus rose" alongside "Muslims claim"). Same verb temperature everywhere.
2. Use each tradition's own terminology first, with translation (salat before "prayer", puja before "worship").
3. Describe practices and beliefs; never rank, praise, or criticize them.
4. Contested classifications follow the Section 2.2 policy: self-identification plus visible contestation note.
5. Misconception entries correct factual errors only, never theological disputes.

---

## 10. Contested-content policy

`contested` is a first-class citizen across every schema (taxonomy nodes, events, matrix cells, influence edges, map polygons via confidence grades). It always renders: badge in UI, dashed line for influence threads, hatching on the map, and a note citing both positions. Silence is never the treatment for a dispute.

---

## 11. Content pipeline and volume

**Workflow per entity:** research → structured draft (one JSON/MDX file per event, tradition, figure, festival, site, term) → source check → contested review → publish. Content lives in a git repo; the site builds from it. No CMS at launch.

**Phase 1 volume at ten traditions:**

| Asset | Volume |
|---|---|
| Events (rank 3+) | ~450 to 600 |
| Deep-dive prose | ~60,000 to 80,000 words |
| Glossary terms | ~300 |
| Matrix cells | ~195 (15 rows x 13 columns) |
| Figures, festivals, sites (structured stubs) | ~400 records |

This is the critical path. At a sustainable solo pace it is months of evenings, not weeks. The schema above exists so none of it is ever redone.
