## Rulings for this slate

1. Default sources: tradition-level rows take both `yao-confucianism-2000` and
   `kohn-daoism-2000`; Confucian rows the former, Taoist rows the latter; every
   row adds `britannica`.
2. BCE rows use the id form `<slug>-bce-<year>` (owner ruling superseding the
   earlier double-hyphen form).
3. Multi-tradition rows: `ricci-in-beijing-1601` adds `macculloch-reformation-2003`;
   `rites-controversy-1704`, `taiping-rebellion-1850`, and `boxer-movement-1899`
   add `macculloch-christianity-2009`. All four are [chinese-traditions, christianity].
4. Rows resting on legendary attribution (the Daodejing's authorship) say so in
   the summary; no contested rows.
