## Sourcing rules for this slate

1. Default: `princeton-dict-buddhism-2014` plus `britannica` s.v. the event
   title on every row.
2. `worlds-parliament-of-religions-1893` is multi-tradition [buddhism, hinduism];
   it adds `flood-hinduism-1996`. `religious-suppression-mao-1949` is
   multi-tradition [buddhism, chinese-traditions]; it adds `yao-confucianism-2000`
   and `kohn-daoism-2000` per the tradition-level rule.
3. Tradition-account events (`bodhidharma-arrives-520`) use attribution framing
   per the occultation precedent and are not contested rows.
4. No contested rows in this slate.
