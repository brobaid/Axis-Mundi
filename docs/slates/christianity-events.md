the owner's reviewer against the Phase 0 rubric. Claude Code ingests mechanically;
nothing here is extended by inference.

## Sourcing rules for this slate

1. Default per the bibliography's era rule: `oxford-early-christian-studies-2008`
   to 600 CE, `macculloch-christianity-2009` for 600-1500, `macculloch-reformation-2003`
   for 1500-1700, plus `britannica` s.v. the event title on every row.
2. New ruling extending the bibliography: post-1700 Christianity events cite
   `macculloch-christianity-2009` (its coverage runs to the present) plus `britannica`.
3. `soviet-antireligious-1917` is multi-tradition; it takes the Christianity
   default for its era plus `ej2-2007` and `nchi-2010` as the affected traditions'
   T1s.
4. No contested rows in this slate.
