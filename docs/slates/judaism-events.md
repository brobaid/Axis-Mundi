## Sourcing rules for this slate

1. Default: `ej2-2007` plus `britannica` s.v. the event title on every row.
2. One contested row: `exodus-narrative--1250`, carrying both positions as
   written. Events resting on the biblical account alone use attribution framing
   in the summary per spec 9.3 and are not contested rows for the occultation
   precedent's reason.
3. Region vocabulary: repo ids only, per the standing rule. No new regions are
   introduced by this slate.
